コザクラインコ遺伝学まとめ（genetics.php準拠）
================================================

■ 性決定システム
─────────────────
ZZ/ZW方式（哺乳類と逆）
- オス: ZZ（伴性遺伝子を2つ持てる＝スプリット可能）
- メス: ZW（W染色体に遺伝子なし＝スプリット不可）


■ 14座位の分類
─────────────────
常染色体劣性 (AR)
  → pied_rec, dilute, edged, orangeface, pale_headed, fallow_pale, fallow_bronze

常染色体優性 (AD)
  → pied_dom

常染色体不完全優性 (AID)
  → dark, violet

常染色体複対立 (AR_MULTI)
  → parblue (aq, tq)

伴性劣性 (SLR)
  → opaline, cinnamon

伴性複対立 (SL_MULTI)
  → ino (ino, pld)


■ 連鎖遺伝（v7.0）
─────────────────
Z染色体連鎖:

  cinnamon ──3%── ino ──30%── opaline
           └───── 31.2% ─────┘

  cin–op の 31.2% は出典の値ではなく、cin–ino(3%) と ino–op(30%) から
  干渉なしで導いた値（子の計算本体と同じモデル）:

    組換えなし          0.97 × 0.70 = 0.679   元の組合せ
    cin–ino だけ組換え  0.03 × 0.70 = 0.021   組換え型
    ino–op だけ組換え   0.97 × 0.30 = 0.291   組換え型
    二重組換え          0.03 × 0.30 = 0.009   元の組合せに戻る

    cin–op 組換え率 = 0.021 + 0.291 = 0.312 = r1 + r2 − 2·r1·r2
    （足し算の 33% は、二重組換えを組換えとして数えてしまう）

常染色体連鎖:

  dark ──7%── parblue


■ 推定ロジック（v7.3）
─────────────────
【家系推定 FamilyEstimatorV3】 座位ごとに、一様な初期値から次の順で絞る:
  1. 本人: 既知の遺伝子型で確定。色に出ていればそのアレルを含む型だけ残す。
     色に出ていないと言い切れるときは、表現する型を除く。
  2. 両親:
     - 既知の遺伝子型から、受け継げない型を除く。
     - 伴性: 娘は父のZを受け取る。表現している母の息子は母のZを必ず持つ
       （持たない型は 0。以前は ×0.5 だった）。
     - 両親とも表現していないときは、メンデル比で重み付けする
       （以前は劣性ホモに一律 ×0.25）。
  3. 子孫 → 4. 兄弟 → 正規化。

  メンデル比: 各親の遺伝子型を、既知ならその型、なければ表現型と矛盾しない型を一様に仮定し、
  子に渡すアレルの確率を求める。子の分布を一様な初期値で割って候補に掛ける。
  入力が矛盾して全候補が 0 になるときは、重み付け前の値を残す。

  例: グリーン×グリーン → グリーンの息子、ダイリュート座位
      各親は ++ / +dil / dil+ のどれか → dil を渡す確率 1/3
      子: ++ 4/9, +dil 4/9, dildil 1/9 → 本人は非表現なので dildil を除き 50% : 50%

  「色に出ていない」と判定する範囲（安全側に限定）:
    - baseColor が COLOR_DEFINITIONS にあるときだけ。不明な色や未入力は判定しない。
    - dark（darkness として別入力）と violet（系統色で見え方が変わる）は判定しない。
    - INO 個体では ino と parblue 以外を判定しない（INO が他の色を隠すため）。
    - 未対応: 親の darkness はまだ推定に使っていない（ダークは Dd 50%, dd/DD 25% のまま）。

【最短世代数 PathFinder::minGenerations】
  プランの手順どおり、各変異を「表現個体 × 野生型」で導入し、系統を並行して進めて合流させる。
    野生型                 → 0
    変異座位が n 個        → 1 + ceil(log2 n) + (固定が必要なら 1)
  「固定が必要」= 野生型アレルを含まない目標型（劣性ホモ、伴性メスのヘミ、DD、tqaq など）がある。
    例: ドミナントパイド 1 / ルチノー・ダイリュート 2 / ピュアホワイト 3
  表現個体どうしを直接交配するような、もっと短い経路は数えない。

【表現型からの確信度 GenotypeEstimator】
  100  確定        表現している劣性、優性が出ていない(++)、伴性メスの非表現(+W)、dark/violet
   50  2通りが同じ見た目  Pi+ / PiPi、Ed+ / EdEd、パリッドのオスの pldpld / pldino
    0  判別不能    劣性の隠れスプリット（オス・常染色体）、INO に隠された座位
  野生型は LOCI の野生型アレルから作る（dd, vv, ++, +W）。
